# H3 提示词编写

本阶段回答“怎样把已锁定计划写成 H3 能直接执行的提示词”。输入是最终 `creative_brief`、`requirement_map`、`bindings`、`developments`、`shots` 和 `audio_plan`；输出完整 H3 提示词。不得新增、删除、合并、拆分或改写已经锁定的内容、镜头和声音。

## 一、选择写作模式

先确定任务模式：

- T2VA、I2VA、FL2VA、L2VA：阅读 [`references/base-zh-en.txt`](references/base-zh-en.txt)；
- Ref2VA：阅读 [`references/ref2va-zh-en.txt`](references/ref2va-zh-en.txt)。

所有模式都阅读 [`references/shared-zh-en.txt`](references/shared-zh-en.txt)，使用其中的镜头、运镜、对白、可见文字和音频写法。官方 reference 决定字段名称、板块顺序、标签和时间格式；本 Skill 决定怎样把锁定计划准确、简洁地放入这些位置。

## 二、分配信息

Ref2VA 必须按以下顺序输出六个板块：

1. `subject_definitions`：定义需要跨镜保持一致、独立控制或被替换的生成语义单元；
2. `summary`：概括任务、素材分工、事件主线和结局；
3. `retention_analysis`：说明各参考出现范围、保留程度和允许变化；
4. `detailed_description`：按时间写可执行镜头；
5. `overall_soundscape`：写持续环境、重复声音主题和总体混音关系；
6. `non_diegetic_music`：写统一的画外配乐方向或 `N/A`。

基础模式按官方 reference 输出 `integrated_multimodal_description`、`overall_soundscape` 和 `non_diegetic_music`。

同一事实只在最合适的位置完整写一次。人物固定外观、环境组成和全局风格不逐镜复述；精确同步声音只在对应 Shot；持续声音不逐镜重复；画外配乐不写进 `overall_soundscape`。

## 三、定义参考与主体

使用真实的 Picture、Video 和 Audio 编号，所有板块保持一致。图片或视频锚点已经清楚提供的静态人物、环境、物体和文字，直接由该标签承担，不再拆成多个 Subject。只有跨多个参考或镜头复用、需要独立运动、属性迁移、替换或独立控制的单元才建立 Subject。

人物的脸、发型、完整服装和固定佩饰通常属于同一人物；背景建筑、家具、天气和光照通常属于同一环境；只有被拿取、操作或独立展示的道具才单列。参考图中的文字默认保留原文和布局；只有用户要求新写、改写，或文字承担精确叙事作用时才转录全文。

## 四、把 Shot 写成执行文本

按锁定时间逐镜转换。每个镜头只写：本镜动作、为完成 `content_purpose` 必需的构图差异、一条摄影机路径、影响连续性的关键状态、边界执行方式和独有同步声音。不要在最终 H3 中解释 `cut_reason` 或规划理由。

从 `start_state` 开始，描述 `action`，并明确到达 `end_state`。关键帧作为本镜起点时，从画面中已经存在的位置、姿态和持物状态继续，不让主体重新入画、重新取得物品或再次到达同一关键帧。

重复使用的全局风格、固定视觉层或转场语法只定义一次。逐镜只说明它在哪个边界启动、承接并落到哪个目标。一个边界只写一次转场，旧画面是否返回必须遵循锁定计划和用户要求。

## 五、写入声音

将 `shots[].sound_cues` 写入对应镜头，只保留精确同步或跨镜关系。将 `continuous_bed`、重复声音主题和 `mix_priority` 压缩为一小段 `overall_soundscape`，不逐镜复述。将 `music_decision` 写成一至两句 `non_diegetic_music`：气质与风格、速度和能量、最多三种核心音色、主要功能，以及必要的混音或结束关系；决定为 `N/A` 时直接写 `N/A`。

不得根据文字润色新增声音，也不得让音频反向改变视觉计划。

## 六、压缩与校验

使用英文书写改写内容；对白、歌词和画面文字保留原语言。采用最短充分表达，不设机械字符上限。逐句判断：删除后若不会损失用户要求、素材绑定、可见事件、连续性、精确同步或 H3 执行信息，就删除。精简不能删掉用户明确动作、顺序、文字、保留项、禁止项、持续效果或音频要求。

交付前逐项检查：

1. 字段、板块顺序、标签和时间格式是否符合所选官方 reference；
2. 每个 requirement 是否有且只有必要的落实位置；
3. 每个 Shot 是否忠实于锁定的开始状态、动作和结束状态；
4. 是否存在未定义或不存在的素材标签；
5. 时间是否连续覆盖目标时长；
6. 是否重复描述 Subject 外观、锚点完整画面、全局风格、转场语法或声音；
7. 最终文本是否新增了计划中不存在的事件、切点、声音或结局。

发现问题时返回所属规划阶段修正；不要在写作阶段悄悄改变计划。
