# 全参考模式改写输出格式指南

本指南说明全参考模式下改写结果的组织方式与写法。

六个改写板块必须全部使用英文。只有 `<d>` 内的对白、歌词，以及画面中实际可见的文字保留原始语言。

**描述详细度：** 写出执行每个镜头所需的具体信息：构图与主体位置、从动作发生到预期结果的可见过程、摄影机行为、相关的光线或环境变化、需要同步的声音，以及参考素材的使用方式。固定外观放在 `subject_definitions`；共享风格放在全局开场描述。镜头中引用这些定义，不重复完整描述，除非用户明确要求重复。完整保留用户的每一项明确要求，不要为了增加篇幅而添加细节。

> 镜头、运镜、说话者、对白和普通声音的基础格式遵循 Shared H3 Prompt Protocol。本指南只说明全参考模式特有的参考标签、分析板块与格式差异。

## 1. 总体结构

完整改写结果按以下顺序包含六个板块：

| 板块 | 作用 |
| --- | --- |
| `subject_definitions` | 定义参考内容及其参考标签 |
| `summary` | 概括任务类型、目标视频和主要参考关系 |
| `retention_analysis` | 说明参考内容如何保留、迁移或复用 |
| `detailed_description` | 按播放顺序描述画面、动作、镜头、声音和对白 |
| `overall_soundscape` | 概括环境声和物理声音 |
| `non_diegetic_music` | 描述只有观众能听见的画外配乐 |

## 2. 参考标签与定义（`subject_definitions`）

全参考改写使用四类标签标识参考内容的来源和用途：

| 标签 | 含义 |
| --- | --- |
| `<Subject N>` | 从参考素材中抽象出的可见内容，可在目标视频中复用或修改 |
| `<Picture N>` | 作为具体目标帧或分镜锚点使用的参考图片 |
| `<Video N>` | 提供编辑底片、续写起点或全片时间结构的参考视频 |
| `<Audio N>` | 被复制或参考的音频信号 |

> 一个参考标签一旦分配给某项内容，就必须在 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 和音频板块中保持同一含义。

`subject_definitions` 定义后续必须独立追踪的参考内容，例如人物、环境、源视频结构或音轨。每项单独一行，说明标签所指内容、参考用途和需要遵循的主要特征；需要明确来源时，写出对应素材。如果 `<Picture N>` 或 `<Video N>` 只用于说明另一项参考内容的来源，后续不会单独分析或使用，就在该项定义中引用它，不另建一行。`retention_analysis` 再记录每项参考内容出现在哪里，以及是完整保留、部分保留、属性迁移还是复用。

### 2.1 `<Subject N>`

`<Subject N>` 用于可复用的可见内容，包括：

- 人物、动物或物体；
- 场景、背景或环境；
- 服装、道具、界面或视觉效果；
- 风格、动作、表情或姿态。

它表示目标视频中实际使用的内容单元，不表示源文件本身。一个 Subject 可以由多个参考素材共同定义，一个参考素材也可以提供多个 Subject。

```text
<Subject 1> is the young woman in <Picture 1>, with long dark hair, a blue cardigan, and a thin silver necklace.
```

同一主体来自多个素材时，合并来源并说明每个素材提供什么：

```text
<Subject 1> is the woman whose appearance comes from <Picture 1> and whose walking motion comes from <Video 1>.
```

### 2.2 `<Picture N>`

当参考图片本身作为某个镜头的首帧、关键帧、尾帧、待编辑关键帧或构图锚点时，单独定义 `<Picture N>`：

```text
<Picture 2> is the first frame of [Shot 1], showing a woman seated beside a café window.
```

如果图片只用于定义人物、场景、服装或风格，不要创建独立 Picture 条目；在对应 `<Subject N>` 定义中引用图片来源。

图片作为故事板或分镜参考时，说明它映射到哪些镜头，以及提供哪些规划信息：

```text
<Picture 3> is a storyboard reference for [Shot 1] and [Shot 2], defining their viewpoint, subject placement, and shot order.
```

### 2.3 `<Video N>`

`<Video N>` 只用于全视频层面的关系，例如：

- 编辑原始视频；
- 从原始视频结尾继续生成；
- 参考原视频的运镜、剪辑、节奏或时间结构。

```text
<Video 1> is the source video for the target video edit.
```

如果复用参考视频中的人物、物体、场景、动作或效果作为可见内容，它们仍应定义为 `<Subject N>`。`<Video N>` 标识素材或结构来源，不能代替 Subject 标签。

### 2.4 `<Audio N>`

`<Audio N>` 表示独立音频素材，或参考视频中已启用的同步音轨。常见用途包括：

- 复制全部或部分音频信号；
- 参考背景音乐风格；
- 参考说话者的音色和表达方式；
- 使用原音频中的对白、歌词或音效；
- 参考节拍、节奏或音频连续性。

当 `<Audio N>` 明确对应目标视频中的说话者时，在定义中复用该说话者的全局 ID：说话者映射到已定义 Subject 时写 `<Subject N> (Sx)`；否则使用稳定的声音描述后接 `(Sx)`。ID 来自目标视频中实际发声事件的全局顺序，不能在音频定义中独立分配或重新编号。说话者编号规则见 5.4 节：

```text
<Audio 1> is the voice-timbre reference for <Subject 1> (S1).
```

一个音频素材承担多个用途时，用一个自然句子说明，不要额外创建子板块。

### 2.5 同一参考视频中的画面轨与音轨

`<Video N>` 与 `<Audio N>` 独立编号。编号只表示各自类别中的标签顺序，不表示二者配对。因此，同一个参考视频可以对应 `<Video 1>` 和 `<Audio 2>`；编号不同不代表来源不同。

普通参考视频不会仅因文件中包含声音就自动产生 `<Audio N>`。

`<Audio N>` 定义主要说明音频用途，不必总是写明它来自哪个 `<Video N>`。只有为消除来源歧义时才说明共同来源，例如：

```text
<Video 1> is the source video for the target video edit.
<Audio 2> is the synchronized audio track of <Video 1> and is reused in the target video.
```

## 3. `summary`

本板块使用一个简短英文段落概括目标视频及其参考关系，并以方括号包裹的任务类型开头：

```text
[reference generation] ...
[video editing + reference generation + audio reuse] ...
```

根据每项参考素材在目标视频中的真实用途选择任务类型：

| 任务类型 | 使用条件 |
| --- | --- |
| `keyframe completion` | 图片作为目标视频的首帧、关键帧、尾帧、待编辑关键帧或其他具体帧锚点 |
| `reference generation` | 图片、视频或音频为人物、场景、风格、动作、运镜、故事板等提供生成指导，但不作为具体帧，也不是被直接编辑或续写的源视频 |
| `video editing` | 直接修改现有源视频；编辑图片或在静态关键帧之间生成不属于此类型 |
| `video continuation` | 从现有源视频继续、延长、恢复或转入新内容 |
| `audio reuse` | 完整或部分复用同一音频信号 |
| `audio reference` | 不直接复制音频，只参考音乐风格、音色、对白或歌词内容、音效质感、节拍或连续性 |

任务同时满足多种关系时，用 ` + ` 组合且不重复。例如，从源视频继续生成并以图片作为尾帧，写作 `[video continuation + keyframe completion]`；编辑源视频并保留原音频，可写作 `[video editing + audio reuse]`。

视频或音频素材的存在不会自动产生对应任务类型。参考视频如果只提供运镜、剪辑或节奏，通常属于 `reference generation`。只有直接编辑或续写该视频时才使用 `video editing` 或 `video continuation`。

编辑源视频且原音频仍可听见时，同时使用 `audio reuse`。续写源视频但不直接复制音频信号，只延续原音轨的可听特征时，使用 `audio reference`。

Summary 使用前面定义的 `<Subject N>`、`<Picture N>`、`<Video N>` 和 `<Audio N>` 描述主要主体、镜头流程和素材用途；不要在本板块新增参考标签。

视频编辑任务在任务类型前缀后以这句话开头：

```text
The target video is an edited version of <Video 1>.
```

## 4. `retention_analysis`

本板块说明每项参考内容在目标视频中如何保留、迁移、复制或参考。每个参考标签占一行，并保持 `subject_definitions` 中已经确定的含义。

### 4.1 可见内容

`<Subject N>`、`<Picture N>` 和 `<Video N>` 使用以下关系标记。这些标记是输出格式中的固定英文值：

| 关系标记 | 含义 |
| --- | --- |
| `fully_preserved` | 完整保留参考内容已定义的用途与特征 |
| `partially_preserved` | 仍使用参考内容，但部分已定义特征发生变化或只保留一部分 |
| `attribute_transfer` | 将参考特征迁移到另一个可识别的目标主体 |
| `weak_reference` | 只保留风格、类别、构图或氛围上的宽泛相似性 |

Subject 条目：

```text
<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - ...
```

Picture 条目：

```text
<Picture 2> ([Shot 1] first frame): fully_preserved - ...
```

Video 结构条目：

```text
<Video 1> (cut and pacing structure): weak_reference - ...
```

### 4.2 音频

`<Audio N>` 使用以下关系标记：

| 关系标记 | 含义 |
| --- | --- |
| `fully_copy` | 完整源音频作为目标视频的完整最终音轨 |
| `partially_copy` | 只复制部分时间线或部分声音层，或者复制后另有声音被增加、移除或替换 |
| `reference` | 不直接复制信号，只参考音色、节奏、音乐风格、对白内容或声音质感 |
| `weak_reference` | 只保留类别或氛围上的宽泛相似性 |

```text
<Audio 1>: fully_copy - <Audio 1> is reused 1:1 as the target video's complete final audio track.
```

```text
<Audio 2>: reference - the target speaker follows <Audio 2>'s voice timbre and measured delivery without copying the original signal.
```

关系标记只能在 `subject_definitions` 已经确定的参考用途范围内选择。目标视频新增的动作、背景或剧情事件，不应被误判为参考保真度损失。

## 5. `detailed_description`

这是全参考改写的主体部分。它按目标视频播放顺序逐镜描述画面、动作、声音和对白，并在相应位置插入参考标签。

### 5.1 基础格式

基础格式遵循 Shared H3 Prompt Protocol：

- 正文使用英文；对白、歌词和可见文字保留原始语言；
- `[Shot 1]` 表示开场镜头，不写时间戳；后续镜头以 `[Shot N] At MM:SS.mmm, ...` 标记切点；
- 运镜以自然英文写在当前镜头中；需要时包含运动类型、幅度和速度；
- 发声来源使用稳定的 `(S1)`、`(S2)` 等 ID；对白和歌词写作 `<d>[Language] ...</d>`；
- 对白跨镜、结尾截断和音频跨镜连续时，使用 `<scenetrans>`、`<cutoff>` 及对应的连续性描述。

关于运镜词汇、多人对白、画外音、跨镜对白和可见文字的完整规则与示例，参见 Shared H3 Prompt Protocol。

### 5.2 全参考模式的差异

| 维度 | T2VA | 全参考模式 |
| --- | --- | --- |
| 主字段 | `integrated_multimodal_description` | `detailed_description` |
| 风格开场 | 写在 `[Shot 1]` 之后 | 在 `[Shot 1]` 前用一至两句英文统一说明 |
| 参考信息 | 不使用全参考标签 | 在首次出现和用途生效处插入 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` |
| 音频关系 | 描述目标视频自身的声音 | 在对应镜头或音频阶段引用 `<Audio N>`，并说明复制还是参考 |

开场示例：

```text
The target video is in a cinematic, literary music-video style with soft lighting and a slightly desaturated color palette.
[Shot 1] The scene opens in a crowded urban street...
[Shot 2] At 00:09.000, the shot cuts to an extreme close-up...
```

生成类任务的 `detailed_description` 通常为 350–500 个英文单词。对白密集内容优先容纳完整对白时间线，不要机械追求字数。视频编辑任务根据源视频复杂度调整长度，不必遵循生成类任务的范围。单镜头不自动意味着描述必须更短；根据每个镜头的信息量分配细节。

### 5.3 在镜头中使用参考标签

固定身份和外观只在 `subject_definitions` 中完整定义一次。重要 `<Subject N>` 每次出现时（包括第一次），使用标签并描述可见动作、空间关系、构图和动态变化，不要重述定义。动作需要时可以点明身体部位或物体，但不重复其固定颜色、材质或造型。用户明确要求重复描述时照做。

具体帧锚点使用自然英文表达：

```text
the shot begins from <Picture 1>
the shot's keyframe corresponds to <Picture 2>
the shot ends on <Picture 3>
```

编辑或续写原视频时，在源状态、结构或续写关系生效的位置自然引用 `<Video N>`。在音频关系生效的镜头或语义阶段引用 `<Audio N>`。

### 5.4 说话者、音频来源和对白

说话者 ID 与 `<d>` 的基础格式遵循 T2VA。参考主体实际发声时，同时保留视觉参考标签和说话者 ID：

```text
<Subject 2> (S1) turns toward the woman and says, <d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>
```

`<Subject N>` 标识参考主体，`(Sx)` 标识实际说话者。主体说话时写 `<Subject N> (Sx)`；同一主体在画外说话时保持相同形式并标记 `off-screen`。说话者不对应已定义 Subject 时，使用稳定的声音描述后接 `(Sx)`。

如果语言内容只是直接复用的 BGM 或完整音轨中的提示，且没有人物、角色、旁白或其他独立发声源实际发声，就以 `<Audio N>` 作为可听来源，不要虚构额外 `(Sx)`。如果声音由具体人物、角色、旁白或其他独立发声源产生，则为该来源分配并复用 `(Sx)`：

```text
When <Audio 1> reaches the phrase <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d>, <Subject 1> performs the corresponding hand gesture without becoming a separate speaker source.
```

直接复用参考音频中的对白、旁白或歌词，或者用户明确要求重新表演这些内容时，在 `<d>` 中保留准确原文和原始语言。听不清的片段写 `[unclear]`，不要猜测或改写。标点只规范为表达句子所需的基础书面符号，例如 `,`、`.`、`?`、`!`；删除重复波浪号、表情符号、项目符号和重复或装饰性标点。完整陈述句、疑问句和感叹句应分别在 `</d>` 前以 `.`、`?`、`!` 结束。

如果只参考音色、节奏、情绪或表达方式，不要把参考音频中的原对白带入目标视频。

按照目标视频中实际发声事件的顺序分配一次 `(Sx)`，并在 `detailed_description` 的每次实际发声中复用。`subject_definitions` 中绑定目标说话者的 `<Audio N>` 定义复用同一 `(Sx)`，但不能独立分配新编号。`retention_analysis` 中不写 `(Sx)`。只存在于直接复用的 BGM 或完整音轨中的语言提示使用 `<Audio N>`；由具体人物、角色、旁白或其他独立发声源产生的声音使用 `(Sx)`。

## 6. `overall_soundscape` 与 `non_diegetic_music`

这两类声音的定义遵循 Shared H3 Prompt Protocol。

`overall_soundscape` 概括全片环境声和物理声音。对白、歌唱以及与特定镜头精确同步的声音事件仍写在 `detailed_description` 中：

```text
overall_soundscape: Quiet indoor room tone and a low ventilation hum continue throughout the video.
```

`non_diegetic_music` 描述角色听不到、只有观众能听到的背景音乐。有配乐时，说明乐器、速度和动态发展：

```text
non_diegetic_music: A restrained solo-piano score at a slow tempo, with sustained low cello underneath and no swell.
```

使用参考音频时，只在与可听层次相符的板块中说明复制或参考关系：环境声和音效写在 `overall_soundscape`；只有观众能听见的配乐写在 `non_diegetic_music`。同一音频同时提供两类内容时，在两个板块分别说明对应关系：

```text
overall_soundscape: The copied ambience layer from <Audio 1> continues throughout the target video.
non_diegetic_music: <Audio 2> is directly reused as the complete audience-only score.
```

完整对白和歌词只能写在 `detailed_description` 的 `<d>` 内，不要在这两个板块重复。
