# H3 音频规划

本阶段回答“观众需要听见什么，以及声音怎样与已锁定画面配合”。输入为用户音频要求、可用音频证据和锁定的 developments、shots 与时间；输出紧凑 `audio_plan`，并为少量精确同步事件补充 `shots[].sound_cues`。

## 一、确认要求与证据

先提取用户明确要求的音乐、静音、原声、对白、歌词、节拍、音色和参考音轨复用范围。只有实际提供并被分析的音频，或用户明确指定使用的视频音轨，才能作为复制歌词、旋律、节拍或音色的依据。图片和视频抽帧只能证明画面，不能证明声音。

声音不得新增、删除、拆分或改写视觉事件、镜头、动作、时间、运镜和结尾画面。声音可以强调已有事件、连接已有切点和组织情绪；视觉与声音偏好冲突时，调整声音。

## 二、选择主要听觉驱动

先选择全片最重要的听觉功能：对白或人声、真实环境、关键动作与冲击、音乐节奏，或品牌与情绪氛围。必要时再选择一个次要功能。不要让每一层都争当主角；`mix_priority` 的最高优先项必须与 `auditory_focus` 一致。

选择最少充分的声音。每个声音至少应帮助说明地点、动作、材质、尺度、节奏、情绪或因果之一。可见物体不自动需要拟音，普通切镜和运镜也不自动发声。物理声音必须有可见或明确的画外来源，并随触发动作开始、变化和停止。

## 三、规划环境与关键声音

`continuous_bed` 记录维持地点、空间或系统连续性的必要底层；不需要时为空。连续底层不逐镜重复。

`key_sound_events` 只记录必须精确同步或对理解、节奏有决定作用的声音，通常保留一至三个。每项包含已有 `shot_id`、可见 `trigger`、具体 `sound` 和 `sync`。相同动作或转场可以共用一个声音主题；相邻切点不要反复叠加同类风切、闪烁或冲击。

声音质感应服从可见材质、尺度和距离。巨大或沉重事件可以有受控低频和结构共振；精密机构适合短促清晰反馈；柔软、液体、空气和颗粒使用与运动相符的质感。只在影响理解时描述远近、遮挡、室内外隔离或混响关系，不为了“立体感”堆砌术语。

## 四、决定是否使用画外配乐

配乐只有在承担环境声、对白和动作声无法替代的功能时才使用，例如统一情绪、组织跨镜节奏、建立类型或品牌质感、支撑高潮。功能不成立时写 `N/A`；用户明确要求音乐或静音时严格执行。

使用配乐时选择一套统一音乐语言：

- `function`：一个主要叙事功能，必要时一个次要功能；
- `tempo_energy_basis`：根据动作速度、有效切点密度和戏剧压力确定速度与能量；
- `timbres`：通常不超过三种相互协调的主要乐器或音色；
- `dynamic_arc`：全片总体发展和一次必要的增强、释放、停顿或结束，不逐镜编曲。

有对白时配乐安静铺底并让出清晰度；环境声承载信息时不遮蔽环境；关键冲击需要保留瞬态和动态空间。除非用户要求反差，音乐能量应与画面能量和段落功能一致。

## 五、确定声音归属与结尾

每个声音只选择一个主要交付位置：

- 独有、精确同步或跨镜延续的声音写入对应 `shots[].sound_cues`；
- 持续环境和重复声音主题交给 `overall_soundscape`；
- 观众听见、角色听不见的配乐交给 `non_diegetic_music`；
- 对白、歌唱和剧情内音乐写在对应 Shot。

`ending_state` 说明主要声音在结尾如何继续、收束、淡出、骤停或进入静默。它必须有用户要求或最后画面的依据。普通切镜、标题或品牌卡不自动让连续环境和配乐突然停止；没有硬停依据时，用降低能量、减少层次、自然余响或短尾韵收束。

## 输出与交接

`audio_plan` 包含：

- `constraints`：用户音频要求、参考复用边界和证据限制；
- `auditory_focus`；
- `continuous_bed`；
- `key_sound_events`；
- `music_decision`，其中 `decision` 为 `use` 或 `N/A`，并包含 `function`、`tempo_energy_basis`、`timbres`、`dynamic_arc`；
- `mix_priority`；
- `ending_state`。

交接前逐项检查：

1. 删除音频计划后，视觉计划是否完全不变；
2. 每个声音是否有用户要求、音频证据或可见触发依据；
3. 主要听觉重心和混音优先级是否一致；
4. 配乐使用与否、速度、能量和音色是否有明确功能依据；
5. 同一声音是否只在一个位置完整描述；
6. 结尾声音状态是否与最后画面一致，未分析音轨是否没有被写成已听见或可复制。

锁定后交给 H3 Prompt Writing Skill。写作阶段只能压缩和分配信息，不能重新设计声音。
