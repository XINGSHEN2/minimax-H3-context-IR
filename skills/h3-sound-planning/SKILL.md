# H3 音频规划

调用方负责解释用户要求、提供素材证据并先锁定视觉大纲与分镜。本 Skill 只规划声音，随后把计划交给 H3 Prompt Writing Skill 写成镜头内声音、`overall_soundscape` 和 `non_diegetic_music`。保持单次模型请求，不增加独立调用。

维护或评估本 Skill 时可阅读 [`references/design-basis.md`](references/design-basis.md)，其中记录官方案例统计与开源资料取舍；普通生成不需要加载该文件。

## 不可改变的边界

音频规划必须在 developments、Shot、动作、时间、运镜、视觉高潮和结尾画面锁定后进行。声音可以强调、连接或重新分配注意力，但不得新增、删除、拆分、合并或改写任何视觉内容，也不得为了配合音乐增加切点、动作、闪光、撞击或标题动画。视觉计划与声音偏好冲突时，保留视觉计划并调整声音。

用户明确要求的音乐、静音、原声、音轨、对白、歌词、音色与复用范围优先。只能把实际提供的音频证据或用户明确指定的带声视频轨写成 `<Audio N>`；图片、无声抽帧和未分析音轨不能证明歌词、节拍、音色或具体声音。证据不足时记录不确定性，不能把推测写成复制关系。

## 规划顺序

在 `content_plan.audio_plan` 中形成紧凑计划，不输出分析过程：

- `constraints`：必须保留的音乐、静音、原声、对白、歌词及参考音频范围。
- `auditory_focus`：全片主要听觉重心，以及必要时的一个次要重心。
- `continuous_bed`：维持地点、空间或系统连续性的环境底层；不需要时为空。
- `key_sound_events`：最多三个重要声音事件，每项对应已经锁定的 Shot ID、可见触发、声音结果和必要同步关系；用户明确锁定更多声音时才可超过三个。
- `music_decision`：对象；`decision` 为 `use` 或 `N/A`，并分别记录 `function`、`tempo_energy_basis`、`timbres` 和 `dynamic_arc`。决定为 `N/A` 时其余字段简短说明由什么声音承担了相应功能。
- `mix_priority`：对白、关键叙事声、环境信息、配乐和辅助拟音之间的主次与让位关系。
- `ending_state`：结尾继续、收束、骤停、淡出或静默的状态及其视觉依据。

先选择主要听觉重心，再选择声音。用户明确指定的声音通常是重心；否则判断视频主要依靠对白／人声、关键叙事声、真实环境、动作冲击、音乐节奏或品牌氛围中的哪一项成立。不要让所有层次同时争当重心，`mix_priority` 的最高优先项必须与 `auditory_focus` 一致。

## `overall_soundscape` 的内容选择

用最少充分的声音建立可辨识的世界：通常选择一个连续底层、一至三个由既有画面直接引起的关键声音，以及一项真正有意义的空间、动态或结尾关系。声音必须至少帮助说明地点、动作、材质、尺度、节奏、情绪或因果结果之一；删除后没有信息损失的拟音应省略。

物理声音必须有可见或明确的画外声源，并随触发动作开始、变化和停止。人物停止行走时脚步声停止；新的撞击声需要新的原因；自然余响可以在原因消失后短暂延续。摄影机运动本身通常没有声音，不要给每次推拉、摇移或普通切镜自动添加 whoosh。

材质和尺度决定声音质感：重量、危险与巨大空间可用受控低频或结构共振；精密界面和小型机构可用清晰短促反馈；柔软材质、液体、空气和颗粒应使用与实际运动相符的质感。只写与当前景别和声学距离相称的声音，不把远处细节写成贴耳特写。

空间关系只在改变理解时写，例如远近变化、室内外隔离、遮挡、画外来源或混响跨切点。普通场景不为追求“立体感”堆叠方位、混响和频段术语。

## 画外配乐判断

只有画外配乐承担环境声、对白和动作声无法替代的主要功能时才使用：跨镜节奏、情绪统一、高潮组织、类型识别或品牌质感。功能不成立时写 `N/A`。未指定配乐属于开放判断，不等于必须添加；用户明确要求配乐、静音或复用音轨时严格执行。

从锁定视觉计划推导配乐，而不是从单个风格词直接套模板：

- 速度依据事件间隔、有效切点密度和主体运动速度；
- 能量依据动作力度、视觉冲击和戏剧压力；
- 音色依据题材、材质、时代、空间和品牌气质，通常不超过三种主要音色；
- 动态弧依据大纲的发展、视觉峰值和结尾状态；
- 混音位置依据主要听觉重心。

快速硬切、连续爆发和强冲击通常需要清楚的节奏或瞬态支撑；缓慢、静止、留白或环境主导的画面适合稀疏持续声或 `N/A`。除非用户明确要求反差，音乐能量不要与画面能量相反。不要逐镜重新编曲；只描述全片主要方向和一次必要的增强、停顿、释放或结束。

## 音画同步与层次

精确同步只用于真正重要的接触、启停、揭示、切点、冲击、文字锁定或动作结果。每个关键时刻选择一个主要声音标点；多个声音同时出现时必须具有不同功能。普通段落维持少量可辨识层次，高潮可以短暂增加密度，随后恢复清晰层级。

对白和用户指定人声优先保持清楚；关键叙事声优先于装饰拟音。配乐在对白下方铺底，在环境声承载信息时让出可听空间，在撞击或短促反馈是重点时保留瞬态与动态空间。声音桥接只能连接已存在的切点，不能反向授权切镜。

角色能听见的音乐属于剧情内音乐，写入对应 Shot；只有观众能听见的音乐才写入 `non_diegetic_music`。参考音轨同时包含环境、对白和配乐时，按用户允许的复用范围分别描述，不能把同一层重复写进多个位置。

## 交接与检查

`shots[].sound_cues` 只保留需要精确同步、跨镜连续或影响动作理解的声音；持续环境和全片声场交给 `overall_soundscape`；画外配乐交给 `non_diegetic_music`。同一声音不在三处重复完整描述。

交接给 H3 Prompt Writing Skill 前检查：

1. 删除全部音频计划后，锁定的视觉内容必须完全不变；`key_sound_events` 只能引用既有 Shot ID，不能为声音新增 beat、development 或 Shot。
2. 每个关键声音都有用户要求、音频证据或锁定画面中的原因。
3. 全片有明确主要听觉重心，辅助层不会遮蔽它。
4. 配乐的使用或 `N/A` 有功能依据，速度、能量和动态弧与画面一致。
5. 结尾声音状态与最后画面一致，不制造新的视觉结局。
6. 未分析的音轨没有被描述成已听见、已转录或可直接复制。
