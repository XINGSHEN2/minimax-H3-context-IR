# H3 音频规划

在同一次模型响应中读取用户要求、素材证据和已确定的视觉计划，形成 `content_plan.audio_plan`，再交给 H3 Prompt Writing Skill。维护时可阅读 `references/design-basis.md`；普通生成无需加载。

## 用户要求与证据

用户明确的音乐、静音、原声、对白、歌词、节拍及参考音轨复用范围优先；未指定部分允许设计。只能把实际音频证据或用户指定的带声视频音轨写成参考复用；无声抽帧不能证明歌词、节拍或音色。缺少证据时记录不确定性。

声音依据已有动作和切点安排，不新增视觉事件或为音效拆镜。若用户指定音轨或节拍与视觉计划冲突，记录冲突并回到规划阶段处理，不以“视觉锁定”为由舍弃用户音频要求，也不在写作阶段暗改时间。

## 选择听觉重点

先确定声音主要如何服务这支视频：环境与空间、动作或剪辑标点、音乐节奏、对白或表演。允许组合，但明确主要重心。安静、冲击、持续节奏和有意留白都可以成立；不默认全片铺满环境声，也不默认压低所有声音。

物理拟音须有动作或明确画外来源，质感与材质、尺度、距离及动作阶段相称。设计音效可以服务已有的光学转场、文字揭示、抽象运动或视觉故障，无需虚构现实声源。普通运镜和切镜不自动配音；有意承担节奏或感知变化的处理可以有声音。

同类转场或动作可共享一个可辨识的声音主题。需要时让它随实际边界重复出现，用一次家族定义明确发生范围、触发点和结束位置；不要把有效的节奏重复误删，也不要让每个边界无区别地发声。重要声音按作用选择，不设固定数量目标或上限；无新增听觉作用的细节才省略。

## 配乐与动态

判断配乐是否承担情绪、节奏、类型或段落组织作用；成立时选择明确的一种主要音乐语言，否则 `N/A`。未指定配乐不等于必须配乐或必须静音。

结合用户节奏意图、整个动作段、切点密度和视觉力度确定速度与能量，不能只按镜头数量套模板。“克制、冷感、极简”可约束音色数量、情绪或混音，不自动等于慢速、低能量；快切也不必始终高响度。音乐可以通过脉冲、重音、留白及短暂释放提供动力，所有主要音色服务同一风格。

用一至两句表达气质与音乐风格、节奏与能量、少量核心音色、主要叙事功能，以及必要的混音或结束关系。通常选不超过三种核心音色，不逐镜重新编曲。对白清晰优先；信息性环境声需要可听空间，关键冲击需要瞬态和动态空间。没有竞争关系时不添加泛化的“全部压低”指令。

根据段落作用选择自然延续、衰减、明确收束、骤停或静默。黑场、标题锁定、品牌揭示或叙事断点可以支持设计性静音，但不自动要求静音。一个明确的有意硬停与无理由的音轨截断不同。若静音作用于整个声场，配乐和环境层也必须遵守，不能同时写余响或继续铺底。

## 计划与交接

保留现有字段，紧凑记录最终选择：

- `constraints`：用户音频要求和参考复用边界；不把自主设计伪装成用户要求。
- `auditory_focus`：主要驱动力、听觉重点及其作用。
- `continuous_bed`：需要的环境连续层及范围；不需要时为空。
- `key_sound_events`：每项含已有 `shot_id`、`trigger`、`sound`、`sync`。声音主题可用首个 Shot ID，并在 sync 中明确其他适用 Shot ID 和触发范围；不为重复边界复制整项。
- `music_decision`：`decision` 为 `use` 或 `N/A`，以及 `function`、`tempo_energy_basis`、`timbres`、`dynamic_arc`。
- `mix_priority`：真实存在的前景、背景及让位关系。
- `ending_state`：声景与音乐最后如何结束、作用于哪些层及段落依据。

为每个关键声音选择落实位置：精确触发或跨镜衔接写入相应 `shots[].sound_cues`，持续层、主要声源及重复声音主题交给 `overall_soundscape`，画外配乐交给 `non_diegetic_music`。剧情内音乐、人声和对白属于对应 Shot。

最终核对最终 H3，而不只检查计划：每个关键声音、同步点或主题范围都有实际文字落实；主要听觉重心没有退化成通用环境底噪；配乐速度、力度和结尾保持原决策；没有相互矛盾的持续声与静音。允许简洁合并和语义等价表达，不能因去重而删除执行信息。缺失则补到所属位置，不能删掉计划项来假装一致。
