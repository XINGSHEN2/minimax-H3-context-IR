# H3 音频规划

本阶段只写 H3 提示词最后的 `overall_soundscape` 和 `non_diegetic_music`。镜头里的对白、动作声和转场声已经写在各个 `[Shot N]` 中，不在这里重新设计镜头。

## 第一步：看用户要求和镜头

先找出用户有没有指定音乐、静音、对白、歌词、原声、节拍或参考音轨。再从第一镜读到最后一镜，记住已经写了哪些声音、它们分别在什么动作发生时响起。用户明确要求的声音必须保留。

不要声称从图片或视频抽帧里听到了声音。只有实际分析过音频，或用户明确要求复用某条音轨，才能写“复制它的歌词、旋律、节拍或音色”。如果镜头里的声音与用户要求冲突，退回分镜修改；不能靠最后两栏掩盖冲突。本阶段不增加视觉动作，也不改镜头时间。

## 第二步：写 `overall_soundscape`

这一栏写画面中的环境声和动作声怎样从开头走到结尾。按播放顺序回答：开场听到什么；主要动作发生时，什么声音加入、变强或暂时盖过原有声音；动作过后，什么声音继续或回来；结束时还听到什么。只写声音确实发生变化的地方，不必每镜写一句。

如果需要持续的背景声，就写出具体听到的声音及其来源，不要只说“低频氛围音”或“环境声持续”。一次冲击或转场可以暂时盖过它；之后还需要背景声，就写清它重新出现。画面不需要背景声时，不强加背景声。声音的远近和强弱要符合画面，不为普通切镜另造音效。

镜头里写某个声音在什么动作发生时响起；这里可以再次提到它，但只写它怎样与背景声连在一起，不复述镜头里的动作。默认直接写声音及来源，不用 `<Subject N>` 或 `<Picture N>` 代替声音；只有多个声源容易混淆时才用标签。

## 第三步：写 `non_diegetic_music`

这一栏只写角色听不到的画外配乐。用户要求音乐或静音时照做；用户没有要求时，先判断视频需不需要配乐，不需要就写 `N/A`。角色说话、唱歌或画面中的设备播放音乐，仍写在对应镜头里。

需要配乐时，用一至两句话写明：什么音乐风格和情绪、快慢与力度、最多三种主要乐器或音色，以及配乐怎样配合视频。配乐负责带动节奏时，要写出观众能听清的节拍或乐器声；只负责营造气氛时，写清观众能听到什么音色，不强加鼓点。全片保持同一种音乐风格，不逐镜换曲风。

再写配乐什么时候让位，什么时候回来，结尾怎样结束。有对白时不能盖住人声；重要的环境声和动作声响起时可以暂时让位，但不要因此让配乐一直听不见。普通切镜和标题出现不自动要求音乐停掉；只有用户要求或画面确实需要静默时才写骤停或近乎消失。

## 第四步：检查并输出

只输出 `overall_soundscape` 和 `non_diegetic_music` 两段英文文字。提交前检查：

1. 用户要求的声音是否保留，未分析的音频是否没有被当成已听见的事实；
2. `overall_soundscape` 是否按播放顺序写清开场、主要变化和结尾，且没有多余的参考标签；
3. `non_diegetic_music` 是否写清配乐实际听起来怎样、何时让位和结尾怎样结束；
4. 镜头与最后两栏是否说的是同一段视频，没有重复描写同一次动作，也没有凭声音增加画面事件。

写完后交给 H3 Prompt Writing Skill 排版，不再改镜头或声音内容。
