# H3 音频规划

读取用户声音要求和全部镜头，完成 `overall_soundscape` 与 `non_diegetic_music`。保留指定音轨、对白、歌词、节拍和静音。图片或视频抽帧不能证明音轨内容；只有实际分析过音频或用户指定复用时，才描述复制哪些声音。不要为声音增加视觉事件或改变镜头时间。

## 第一步：写整体声景

`overall_soundscape` 按播放顺序写：开场听见什么，动作发生时什么声音加入或改变，之后哪些声音延续，最后怎样结束。只写有变化的阶段，不逐镜复述动作。

背景声需要持续时，写具体声源和听感。也可以根据作品设计氛围持续音，说明音色和作用，不只写“低频氛围”。重要动作声结合镜头中已经确定的触发过程，交代它怎样进入背景、掩盖背景或留下余响。距离、材质和空间影响听感时才描述，不堆叠音频术语。

背景声被冲击暂时盖住后，若场景继续，就交代它何时恢复。切镜、闪白、短黑场和标题出现本身不要求声音中断；只有用户指定或已设计的声音停顿才写静音。声音不必持续增强，也不必在结尾一律减弱。

镜头正文负责声音发生的准确动作，这里负责全片的延续和变化，可以提及同一声音但不抄回整段动作。直接写声音名称和来源，只有不加标签会混淆声源时才用 Subject 或素材标签。

## 第二步：写画外配乐

`non_diegetic_music` 写角色听不到的配乐。用户要求音乐或静音时照做；未指定且不需要配乐时写 `N/A`。画面内说话、演唱或设备播放的声音归入镜头和整体声景。

需要配乐时，简洁写明风格、情绪、节奏和主要乐器或音色，再说明怎样配合视频。带动节奏时写清可辨认的节拍或乐器声，营造气氛时写清持续音色。用一种统一音乐语言，不为丰富而逐镜换风格。

交代配乐与对白、环境声和重点动作声的关系：需要时暂时让位，之后继续，不把“不能盖住音效”写成整片都听不见音乐。结尾可延续、衰减或明确停下，选择与画面结束方式相符的一种，不因切黑自动骤停。

## 检查与交接

输出两段英文文字。核对用户要求、镜头中的同步声音和这两段是否一致；背景与配乐没有无故消失；没有新增画面事件。之后交给 H3 Prompt Writing 按官方六板块格式交付。
