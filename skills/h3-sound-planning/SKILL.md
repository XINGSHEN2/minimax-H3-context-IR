# H3 音频规划

在视觉大纲和分镜确定后形成紧凑 `audio_plan`。声音可以强调已有事件、连接已有切点和组织情绪，不得新增视觉事件或为声音拆镜。用户明确指定的音乐、静音、原声、对白、歌词、节拍及参考音轨范围优先；只有实际音频证据才能作为复制或复刻依据。

## 选择声音

先判断视频主要由环境、动作／剪辑声音、音乐或人声中的什么驱动，再选择最少充分的声音层。保留用户指定项，以及能够建立场景、解释关键动作、强化尺度或形成剪辑节奏的声音。可见物体和动作不自动需要拟音；删除后不影响理解或体验的自主细节不进入计划。

同类转场或重复动作可以共享一个声音主题，一次定义其质感和触发范围。普通切镜和运镜不自动发声。物理声音须有可见或明确的画外来源；设计音效可以服务已有的光学转场、文字揭示、抽象运动或视觉故障。

## 配乐

配乐只在承担情绪统一、节奏推进、类型识别或段落组织时使用，否则写 `N/A`。结合用户意图、动作力度和有效切点密度决定速度与能量；“克制、冷感、极简”不自动等于慢速或低能量。

选择一套统一的音乐语言，通常不超过三种核心音色。`dynamic_arc` 只记录总体发展和不可缺少的转折，不逐镜编曲。对白优先清晰，信息性环境声和关键冲击保留必要空间。结尾可自然延续、收束、骤停或静默，由用户要求和段落功能决定。

## 计划字段与归属

- `constraints`：仅记录用户音频要求、参考复用边界和证据限制，不写自主设计。
- `auditory_focus`：主要听觉驱动力及作用。
- `continuous_bed`：必要的持续环境层及范围；不需要时为空。
- `key_sound_events`：只记录不能由持续声场或配乐概括的关键同步。每项包含已有 `shot_id`、`trigger`、`sound`、`sync`；没有必要时可为空。
- `music_decision`：`decision` 为 `use` 或 `N/A`，并包含 `function`、`tempo_energy_basis`、`timbres`、`dynamic_arc`。
- `mix_priority`：实际存在的主要前后关系。
- `ending_state`：结尾各主要声音层的状态。

每个声音只选择一个主要交付位置：独有的精确同步写入对应 `shots[].sound_cues`；持续环境和重复声音主题交给 `overall_soundscape`；画外配乐交给 `non_diegetic_music`；对白、歌唱和剧情内音乐属于对应 Shot。全局主题已说明范围后，不再逐镜重复。

交接前核对用户音频要求、主要听觉重心、关键同步、配乐方向和结尾状态均有明确归属，且持续、停止和静音没有冲突。覆盖按最终文本的语义并集判断，一处清楚表达即可。
