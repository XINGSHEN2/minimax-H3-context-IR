# H3 分镜规划

本阶段只回答“怎样让观众清楚、连贯地看见已经锁定的内容”。输入为 `developments`、素材绑定、视觉风格、目标时长，以及用户明确指定的镜头和剪辑要求；输出按时间排列的 `shots`。

不得新增、删除或改写 development。若大纲缺少必要事件或前后矛盾，应退回大纲阶段，不能在分镜中补写故事。

## 第一步：确定观看任务

依次读取 developments，判断观众为了理解内容必须看清什么：动作的执行者与结果，人物、物体和空间的关系，用户要求展示的材质、功能、文字或反应，以及素材锁定的关键构图或动作节点。

每个 Shot 必须写明 `development_ids` 和 `content_purpose`。`content_purpose` 说明本镜不可替代的观看价值，不写“增强节奏”“更有电影感”等抽象理由。

## 第二步：决定是否切镜

先尝试用一个连续镜头完成同一时间、空间、主体和动作目标。通过主体运动、摄影机跟随、重新构图、景别变化或焦点变化能够清楚呈现的信息，留在同一镜头。动作的准备、执行、即时反应和直接结果通常保持连续。

只有以下情况需要切镜：

1. 时间或空间发生变化；
2. 叙事主体或观察关系发生变化；
3. 当前连续观察路径无法清楚呈现必要信息或结果；
4. 用户或参考明确规定切点或镜头结构。

广告、蒙太奇、舞蹈卡点和产品展示可以使用覆盖镜头，但新镜头仍须提供当前镜头无法替代的信息，不能只换角度重复同一状态。“快切、硬切、广告节奏”等词控制已有切点的表现和速度，不自动产生更多切点。

标题变化、闪白、黑场、故障、震动或普通反应要附着于它所表现的动作或已有切点；仅要求这种效果出现，不等于要求独立 Shot。只有用户或参考明确指定独立片段、标题卡或黑场镜头时，才单独成镜。

一个 Shot 可以承载多个连续 developments。一个 development 只有在确实需要不同观察关系时才跨多个 Shot；此时后续镜头填写具体 `cut_reason`。若拆开未完成动作，再填写 `continuity_bridge`。无法说明新增信息的镜头应合并。

## 第三步：设计镜内执行

每个镜头选择一个主要构图和一条摄影机路径。运镜只用于跟随动作、揭示关系或改变观看重点；没有明确作用时保持稳定。不要同时写互相冲突的固定机位和移动指令，也不要堆叠无关运镜。

一个 Shot 只表现同一连续时空中的一个主要动作进程。它可以包含依次发生的动作阶段和渐进构图变化，但不能把不同时间、不同空间或互不连续的事件塞入同一镜头。

关键帧作为镜头起点或目标时，第一次清晰可辨的画面就应落在锁定的主体位置、姿态、持物状态、景别和构图。除非用户明确要求主体入画或摄影机寻找主体，不要再次到达同一关键帧。

## 第四步：保持连续并安排时间

每镜填写 `start_state`、`action` 和 `end_state`。后镜从前镜已经到达的状态继续，检查主体位置、动作阶段、运动方向、视线、物品归属、服装和环境状态。不得重启已经完成的动作，不得无依据恢复旧状态或重复关键帧。

每个镜头边界只执行一次转场：前镜结束旧内容，边界完成替换，后镜直接从新内容继续。跨边界运动保持同一方向和速度趋势；目标内容第一次可辨识时已经落在目标构图。除非用户或参考明确要求闪回、叠化保留或返回，旧内容不得重新清晰。用户要求的硬切、闪白、黑场、故障或有意跳切必须保留。

对保留的切点，向最终 H3 写作明确交接切换方式、切入对象和切入后第一帧的状态。最终描述应让新镜头从具体内容开始，例如“镜头硬切至……”，但不强制使用固定句式。短黑场、闪白等短暂效果若用于连接两镜，只在边界的一侧描述一次，不在前镜结尾和后镜开头重复执行；它们不应凭空延长动作或让旧画面重新出现。

按动作持续时间、信息阅读时间和节奏分配镜长。时间从 0 连续覆盖目标时长，不平均切分，也不追求固定镜头数量。不要为了结束镜头制造停顿。

## 输出与检查

每个 Shot 至少包含 `id`、`development_ids`、`content_purpose`、`treatment_ids`、`start_seconds`、`end_seconds`、`start_state`、`action`、`end_state` 和待声音阶段填写的 `sound_cues`。需要时加入 `cut_reason` 和 `continuity_bridge`。

锁定前只检查四件事：

1. 每条 development 是否完整呈现，且没有新增事件；
2. 每个切点是否来自四类有效理由，并提供非重复信息；
3. 相邻镜头的动作、主体、物品和目标关键帧是否连续且不重复；
4. 摄影机、转场和时间是否清楚、单一且可执行。

锁定后交给 H3 Sound Planning Skill。声音只能引用已有 Shot，不能反向增加动作、切点或视觉结果。
