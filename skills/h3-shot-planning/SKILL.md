# H3 分镜规划

本阶段回答“每个镜头具体让观众看见和听见什么”。输入为 `developments`、素材绑定、视觉风格、目标时长，以及用户明确指定的镜头、剪辑和声音要求；输出按时间排列的 `shots`。最终 `h3_prompt.detailed_description` 中的每个 `[Shot N]` 是可直接用于 H3 的英文逐镜正文，不是供后续阶段扩写的提纲。遵循 H3 Prompt Writing Skill 的参考标签、语言和信息分配规则。

不得新增、删除或改写 development。若大纲缺少必要事件或前后矛盾，应退回大纲阶段，不能在分镜中补写故事。

## 第一步：确定观看任务

依次读取 developments，判断观众为了理解内容必须看清什么：动作的执行者与结果，人物、物体和空间的关系，用户要求展示的材质、功能、文字或反应，以及素材锁定的关键构图或动作节点。

每个 Shot 必须写明 `development_ids` 和 `content_purpose`。`content_purpose` 说明本镜不可替代的观看价值，不写“增强节奏”“更有电影感”等抽象理由。

## 第二步：决定是否切镜

先按时间顺序确定每段内容的观看目标：观众需要看清什么初始状态、动作或展示过程，以及直接结果。对于同一时间、空间、主体和动作目标，先设计一个连续镜头，通过主体运动、摄影机跟随、重新构图、景别渐变或焦点变化呈现这些阶段。一个镜头可以有多个有序阶段，不要求机位和景别始终不变。不要仅因动作进入下一阶段、需要展示局部细节或人物作出即时反应，就自动增加 Shot。

只有切镜能提供当前连续观察路径无法清楚呈现的必要内容，或切换本身有明确作用时，才建立新 Shot。有效理由包括：时间或空间改变；观察主体或关系改变；必须独立看清的细节、结果或反应无法在当前镜头呈现；用户或参考明确指定切点、视角或镜头结构；剪辑节奏本身承担明确的展示或表达作用。每个新增镜头都要指出它提供的新信息或作用，不能只换角度重复同一状态。

广告、蒙太奇、舞蹈卡点和产品展示允许有目的的覆盖镜头。用户要求“快切、硬切、广告节奏”时，应让必要切点符合该节奏，但这些词本身不要求把每个动作阶段拆开。用户或参考明确给出多个画面、分镜板或同步节点时，按其结构保留必要切换；不要为了延长单镜而强行合并。

标题变化、闪白、短黑场、故障和震动，通常写在承载内容的镜头内部或已有切点上，不因效果短暂出现就单独建立 Shot。人物反应若能与触发动作在同一连续观察中看清，留在该镜；若必须改变观察对象才能看清，或反应本身承担独立的表达作用，可以切镜。用户或参考明确要求独立标题卡、黑场段落或其他独立片段时，按要求成镜。

一个 Shot 可以承载多个连续 developments；一个 development 也可以跨越确有必要的不同观察关系。跨镜呈现同一未完成动作时，后镜必须从已到达的动作阶段继续，并填写具体 `cut_reason` 和 `continuity_bridge`。完成初步分镜后逐个尝试删除切点：如果前后内容能在同一连续镜头中清楚呈现，且切换没有独立的信息或表达价值，也不违反用户及参考结构，就合并。合并后的镜头仍须让动作阶段、关键细节和直接结果清晰可见。

## 第三步：设计镜内执行

在最终 `h3_prompt.detailed_description` 中为每个 Shot 直接写完整正文：从具体的起始画面写起，交代本镜必须看清的人物与物体特征、相对位置、前后景和空间尺度；按时间顺序写动作或展示怎样展开，物体状态怎样变化，必要的材质纹理、光线和环境如何随之显露；写明摄影机怎样观察、结束时画面留下什么状态，以及需要的切点。不能只给一个动作名称、景别或运镜，再期待最终写作阶段补出画面。

静态身份和环境可用已定义的 Subject、Picture 或 Video 标签引用，不逐镜复述完整定义；但本镜的观看重点必须具体可见。若用户要求看清某种材质、结构、文字、尺度或人物表现，说明它在什么构图、动作和光线下被辨认，而不是只列形容词。只使用与用户目标和素材证据相符的特征；开放补全也要服务本镜内容，不能为了写长而新增事件或物体。静态展示不强造动作，简单动作不强行延长。

每个镜头选择一条连续的摄影机路径。运镜只用于跟随动作、揭示关系或改变观看重点；没有明确作用时保持稳定。一个 Shot 可以在同一连续时空中包含有序动作阶段、景别渐变和焦点变化，但不能拼接互不连续的事件，也不能同时要求固定机位和摄影机移动。

把必须与画面精确同步的声音穿插在对应 `[Shot N]` 的时间进程中：写到触发动作、材质接触、人物发声或切点时，紧接着交代观众同时听见的声音及其必要的变化。声音应像动作的一部分自然嵌入叙述，而不是先写完整段画面、再在镜头末尾集中补一串 `Sound:` 或音效清单。没有局部同步声音的镜头不必为形式完整而添加。用户指定的对白、可见动作的关键反馈和必要的局部转场声要有用户要求、已分析音频或明确可见的触发依据；不为每个物体和普通运镜添加拟音，不在逐镜文字中编排全片环境底层或画外配乐。声音不得创造新的视觉事件。

关键帧作为镜头起点时，首次清晰可辨的画面应符合锁定的主体位置、姿态、持物状态、景别和构图。关键帧作为镜头目标时，写清通过什么连续过程首次到达该构图；不要提前呈现完成态，也不要到达后重复同一关键帧。除非用户明确要求主体入画或摄影机寻找主体，不额外增加寻找目标的过程。

## 第四步：保持连续并安排时间

直接从相邻 `[Shot N]` 正文 检查起始画面、动作阶段和结束画面。后镜从前镜已经到达的状态继续，核对主体位置、运动方向、视线、物品归属、服装、环境及跨镜声音状态。不得重启已经完成的动作，不得无依据恢复旧状态或重复关键帧。

每个镜头边界只执行一次转场：前镜结束旧内容，边界完成替换，后镜直接从新内容继续。跨边界运动保持同一方向和速度趋势；目标内容第一次可辨识时已经落在目标构图。除非用户或参考明确要求闪回、叠化保留或返回，旧内容不得重新清晰。用户要求的硬切、闪白、黑场、故障或有意跳切必须保留。

对保留的切点，在相邻 `[Shot N]` 正文中明确切换方式、切入对象和切入后第一帧的状态。新镜头直接从具体内容开始，不强制使用固定句式。短黑场、闪白等短暂效果若用于连接两镜，只在边界的一侧描述一次，不在前镜结尾和后镜开头重复执行；它们不应凭空延长动作或让旧画面重新出现。

按动作持续时间、信息阅读时间和节奏分配镜长。时间从 0 连续覆盖目标时长，不平均切分，也不追求固定镜头数量。不要为了结束镜头制造停顿。

## 输出与检查

每个 Shot 至少包含 `id`、`development_ids`、`content_purpose`、`treatment_ids`、`start_seconds`、`end_seconds` ；最终英文逐镜正文只写在 `h3_prompt.detailed_description`。需要时加入供检查的 `cut_reason` 和 `continuity_bridge`。最终逐镜正文使用独占行首的 `[Shot N]` 标签，编号与 `shots` 元数据一一对应；不要另输出一套完整的 `start_state`、`action`、`end_state` 或 `sound_cues` 正文。

锁定前只检查四件事：

1. 每条 development 和用户明确要求是否在逐镜正文中落实，且没有无依据的新事件；
2. 每个切点是否有有效理由并提供非重复内容；删除无价值切点后，保留镜头能否完整呈现动作、细节和结果；
3. 每镜的具体主体、空间、材质或光线如何被看见是否足够清楚，摄影机路径与时间是否可执行；不能把关键画面细节留给后续写作补充；
4. 相邻镜头的动作、主体、物品、关键帧、转场和局部声音是否连续且不重复。

锁定后交给 H3 Sound Planning Skill 汇总全片声景和画外配乐。`h3_prompt.detailed_description` 中的逐镜内容已是最终镜头正文；后续只能按 H3 格式排版，不能重新设计或扩写镜头。
