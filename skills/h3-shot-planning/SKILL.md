# H3 分镜规划

输入是用户要求、素材用途、`developments` 和目标时长。输出 `shots` 及 `h3_prompt.detailed_description` 中的 `[Shot N]` 正文。遵守 H3 Prompt Writing Skill 的标签和语言格式。

## 第一步：安排观看过程和时间

先沿着大纲安排观众从开头到结束看见什么，再决定镜头数量。给动作发展、细节辨认和必要停留合理的时间。能同时发生的动作、环境反应和文字动画结合呈现，不默认排成“动作结束后再播放文字”的两段；用户指定的顺序或独立展示除外。

检查主要过程在什么时候结束，余下时间具体呈现什么。已有内容不足以支撑时长时，调整动作的发展与观看时间；不要用重复冲击、额外收尾或长时间停在同一状态上补齐。用户要求的静态展示、停顿或持续镜头照做。确实需要增加事件时先修正大纲，不在镜头正文中偷偷加入。

## 第二步：保留有用的切点

先把同一连续时空中的同一个动作从开始、发展到直接结果写成连续镜头，再检查是否确实需要拆开。动作变强、出现闪光、人物受到冲击或景别改变，本身都不是切镜理由；能在当前镜头里通过主体运动、摄影机移动、重新构图或焦点变化看清，就继续拍下去。只有必要内容仍无法看清、时间地点改变，或用户、参考明确规定切点或独立片段时，才增加 Shot。用户明确要求蒙太奇、卡点或独立展示时，保留完成该要求所需的镜头。

“快速硬切”“电影感”决定已有切点怎样表现，不用于推算镜头数量或平均镜长。黑场、闪白和故障是视觉效果，不自动成为独立镜头；模型自行安排的效果位置不算用户指定的切点。同一版式的主副标题在同一个 Shot 内完成，依次显现和中间闪黑都可留在该镜。只有用户明确要求分镜或独立标题卡时才拆开。

保留切点前，明确后镜增加了什么必须看见、而当前镜头无法呈现的内容。不能只回答“更紧张”“换个角度”或“加强节奏”。前后镜仍在展示同一次震动、同一次启动、同一次冲击或同一组标题变化时，优先合并；只多看一个角度或重复展示材质不足以保留切点。用户明确指定的切镜结构除外。不同主体不必各占一镜，能同框看清动作及反应时可一起呈现。

## 第三步：写出具体镜头

每镜正文依次写清起始画面、可见过程和结束状态：谁和什么在哪里；主体怎样行动；相关物体如何响应；摄影机怎样观察。物品被拿取前先交代位置和持有者；门、盖子等状态改变时写明动作。固定外观用 Subject 或 Picture/Video 标签引用，本镜重要的结构、材质、光线、文字或表情仍须具体写出，不能只说“展示产品”或“发生冲击”。

参考素材的局部修改必须落在出现该内容的镜头中：说明原来哪项内容改成什么，准确写出目标文字、物品状态或替换台词，不能只在前三栏提到。用户未要求改变的内容继续保留。

每镜使用一条连贯的摄影机路径，运镜用于跟随、显露关系或改变观看重点；无需移动时保持稳定。不同时间或地点的事件不塞进同一连续镜头。指定关键帧首次清晰时就符合其位置、姿态和持物状态；若需运动到达目标帧，写清路径，到达后不再重复。

同步对白、动作声和必要转场声写在触发它的动作旁，自然穿插，不在镜尾追加音效清单。没有需要强调的局部声音就不补写。持续环境声和画外配乐由 Sound Planning 统筹；黑场不自动要求静音。

## 第四步：连接镜头并核对时间

对照前镜结束与后镜开始，检查人物位置、动作阶段、物品归属和状态、服装及需要延续的声音。未发生改变就保持原状态；离开画面的物品再次可见时也要接上。拆分同一连续动作时填写 `cut_reason` 和 `continuity_bridge`，不能把自行设计的效果说成用户指定的切点。

每个切点说明从什么画面离开、怎样切换、下一镜首先看见什么。甩镜写方向和落点；短黑场、闪白或遮挡只在边界一侧描述一次。除非要求闪回或返回，不让已经被替换的画面再次清晰，也不重新执行已完成动作。

各镜时间从 0 连续覆盖目标时长。逐镜确认内容能自然支撑所占时间，不平均分配。`[Shot 1]` 不写时码；从 `[Shot 2]` 起只在编号后写切点时间。正文用先后关系描述动作，不再写具体时码。

## 输出与交接

每个 `shots` 条目写 `id`、`development_ids`、`content_purpose`、`treatment_ids`、`start_seconds`、`end_seconds`；拆开同一连续动作时另写 `cut_reason`、`continuity_bridge`。镜头文字只写在 `h3_prompt.detailed_description`，以独占行首的 `[Shot N]` 连续编号，与 `shots` 一一对应。

交接前检查：明确要求确实出现在镜头正文；没有把效果要求误当切镜要求；主副标题完整展示在同镜；状态前后相接；动作和镜长相称。发现问题就修改对应镜头及时间记录。之后交给 Sound Planning，H3 写作只负责六板块交付，不另编镜头。
