# 音频描述归纳依据（2026-09-10）

## 范围与证据边界

阅读 Feishu 案例树中原始 `output/official_ir/official_ir_prompt.txt` 的声音段落，覆盖 1.1–1.10、2.1–2.3、3.1–3.4 中已有文件；未把 duration_fixed 或本地版本作为新的官方样本。此前详细对照过 1.1 与 2.2 九例的分镜和声音。此次是文本研究，不是所有视频的听音评测。

本地素材根目录为 `/home/mx/shenxing/minimax-H3-data/minimax-H3-feishu-cases`。下表的小类／Case 可在该目录定位；原用户要求保存在各例 `output/official_ir/official_ir_request_manifest.json`。没有逐例核实用户要求的观察，只称“官方输出选择”，不称官方主动创作规律。

## 条件规律与反例

| 案例 | 官方文字选择 | 可迁移经验与边界 |
|---|---|---|
| 1.1 Case1 | 拨弦、轻打击乐，与望远镜转场匹配 | 简洁不等于慢；不能给所有时尚广告配缓慢音乐盒 |
| 1.1 Case3 | 低频脉冲、金属震动、标题重音；配乐 N/A | 用户本来指定了这些声音，不能算官方自主补全；无需再加一套低音配乐 |
| 1.1 Case5 | 火声、VHS 噪声与强电子节拍 | 有动机的强烈声音可以成立，不能一律稀疏化 |
| 1.6 Case2 | 慢速电子氛围、数字音色与机械调整声 | 抽查用户要求是未来感慢运镜椅子展示，未指定配乐；这是风格到可听音色的补全例，不是所有产品都应电子乐 |
| 1.5 Case2；1.10 Case3/5 | 争吵或对白居前，音乐 N/A | 不默认给对话添加旁白或配乐；其他 1.10 案例却有轻伴奏，因此对话也不必永远无音乐 |
| 1.9 Case6 | 冰块、雪茄、衣料与呼吸，音乐 N/A | 近距离质感可由物理声音承担，不需通用氛围底乐 |
| 1.9 Case1 | 奔跑阶段打击乐推动，慢动作跳跃时悬停式高潮 | 声音变化跟随动作发展，不按图片数量或固定秒数切换 |
| 2.2 Case1/3 | 笑声互动／歌唱表演，配乐 N/A | 人物声音不是都要禁；短笑声与持续笑声需取决于表演 |
| 2.2 Case4；1.8 Case2 | 源音乐或机械声复用，结束后回到环境声 | 先确认源音轨关系，再考虑补乐；官方声称复用不等于当前服务实际完成复用 |
| 2.1 Case1 | 源节拍和人声采样为主，不额外加环境声 | 纯音乐驱动也成立，不能强迫每片加自然音 |
| 2.1 Case3 | 微观粉末声过渡到沙漠风声，配乐 N/A | 通过音色变化衔接尺度；不是每次转场都加 whoosh |

## 社区借鉴与未采用项

- [OpenMontage sound-design](https://github.com/calesthio/OpenMontage/blob/main/skills/creative/sound-design.md)：借鉴声音主次、人声可懂度与动作音效的关联。其固定音量、均衡、平台响度表不作为 H3 控制参数，也不视为已独立核实的行业统一规范。
- [OpenMontage music-gen-usage](https://github.com/calesthio/OpenMontage/blob/main/skills/creative/music-gen-usage.md)：借鉴风格／节奏／音色／动态的描述方法与连贯配乐。未采用固定 BPM 表、调性情绪映射、所有背景音乐必须纯器乐、价格和供应商执行代码。
- [ElevenLabs 官方 music Skill](https://github.com/elevenlabs/skills/blob/main/music/SKILL.md)：参考音乐方向和分段动态表达；本 Skill 不依赖其 API，不生成音频文件，也不引入作曲计划 Schema。
- 本仓库 `skills/h3-prompt-writing/references/ref-en.txt` 与 `base-en.txt`：输出结构、音频引用、说话人和声音分区的依据。官方样本偶尔重复音乐或存在描述歧义，不机械模仿。

以上为独立归纳，未复制社区的整段规则或执行脚本。

## 后续行为核验

用相同素材证据、目标时长和模型参数对照 v20：

1. 无对白商品片：不能把标签朗读出来；合理配乐仍可补全。
2. 明确保留原音乐：不能因缺少音频分析改成 N/A；也不能虚构已启用的音轨。
3. 纯机械演示：动作声清楚，不默认加音乐。
4. 对话与合唱：分别保护对白可懂度和明确要求的合唱，不能全局禁人声。
5. 快切广告与安静近景：允许不同密度，不硬套同一方案。
6. Logo 后继续音乐：不因案例先验强行静音。

这些是待运行的行为场景，不是已经通过的音视频效果测试。
